截图占位。当前为空，请自行添加：

- `preview-desktop.png` (1920×1080) — web 版桌面截图
- `preview-mobile.png`  (iPhone 14 Pro / Pixel 7 模拟) — mobile 版截图
- `preview-modal.png`   (1280×800) — 捕获大卡截图

文件添加到本目录后，README 会自动引用。

## 推荐截图工具

- macOS: `Cmd+Shift+4`
- Chrome DevTools: 右键 → Capture screenshot → 选 viewport 或 full size
- macOS Safari: 启用 Web Inspector → 右键节点 → Capture Screenshot
- 在线：https://screely.com / https://shots.so
